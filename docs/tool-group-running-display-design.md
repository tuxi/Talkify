# macOS 工具组运行态展示（已确认）

工具组标题以真实执行状态为依据，与展开、收起独立。沿用工具组默认收起、用户手动展开、组整体不设最大高度的规则。

## 标题

- 存在正在执行的工具或后台任务：展示第一个仍在执行的条目的简短动作标题。优先使用工具已有动作说明，完整命令在工具内部查看。
- 多项并行：当前标题旁提示其余运行数量。保持条目顺序，当前项结束后再切换到下一项，避免无意义轮播。
- 暂无工具执行：显示归集名称。本轮仍在继续、思考或等待下一次调用，不再触发「正在处理」的通用标题。
- 全组完成：保留归集名称，停止运行标记与骨架。
- 历史失败数独立保留，不覆盖当前执行标题。持续时长仍表示整组墙钟时间，不是各工具耗时之和。

## 运行标记

在组头标题左侧放置四个暖橙色小圆点，缓慢环转并依次明暗变化。使用独立绘制的圆点，去掉字符 `•••`。不恢复每个工具的图标。

标记占据标题外侧的小位置，保持组头文字与正文左对齐，不增加组头左右内边距。窄窗口同样保证圆点完整显示。工具间隙使用更慢的转动，标题保持归集名称。

## 骨架与内容

- 组收起：只显示组头，不渲染骨架。
- 组展开、工具仍收起：组尾显示一处两条不同长度的浅灰流光，表达待填充状态。
- 执行中的工具展开且没有输出：骨架放在命令下的输出位置，隐藏同一等待状态在组尾的重复骨架。
- 真实输出到达：显示真实内容，不用骨架覆盖或替换已有输出。
- 工具间隙：本轮仍在接收内容时，可在组尾保留一处骨架。
- 完成、失败或取消：对应的运行标记和骨架随真实状态移除，保留用户的展开选择和已存在的内容。

四点环转一周约 2.8 秒，工具间隙约 4.2 秒；骨架流光约 2.2 秒。启用系统「减少动态效果」时显示静态标记与占位条，不循环动画。运行标记提供可访问状态名称，骨架不按动画帧播报。

## 验证

检查组头在展开与收起时一致；并行项稳定切换；暂无工具执行时立即恢复归集名称；真实输出替换占位；完成后移除运行效果；流式更新不重置展开状态。使用真实 WebKit 验证窄窗口布局和骨架去重。
