## 主要方向

1. 用户消息使用无明显边框的浅灰气泡；回复直接排在页面上。
2. 正文用高对比深灰；工具与过程信息用次级文字色。灰度区分层级，不用整段淡灰降低可读性。
3. 用稳定的段落、列表和工具外部间距形成节奏；避免每个块都增加标题、卡片、分隔线或状态标签。
4. 工具摘要、名称、展开内容沿用现有语义；只约定周围间距、字体和轻边框。具体展开机制由工具展示专项负责。
5. 移除常驻“下次发送”“最近 Turn 路由”“最近实际响应”三行调试信息。模型选择仍在输入框底部；实际需要诊断时走独立调试入口。
6. 时间、复制等辅助项在 hover 或键盘焦点时出现；预留行高，出现时不推动正文。

## 建议初值（macOS 逻辑 pt）

| 项目 | 建议 |
| --- | --- |
| 正文 | 系统字体 Regular，15 / 25 |
| 内容标题 | 16 / 24，Semibold；避免一串过大的 Markdown 标题 |
| 工具与过程信息 | 13.5 / 22 |
| 辅助信息 | 12 / 20 |
| 代码 | 系统等宽字体，12.5 / 21 |
| 段落间距 | 14 |
| 列表项间距 | 6 |
| 正文与工具区域 | 18–20 |
| 两轮之间 | 32–36 |
| 用户消息与回复 | 24，另预留辅助操作的 20 高和 7 上边距 |
| 工具单行最小高度 | 36，保持现有点击/展开功能；实际多行内容不强行裁到单行 |
| 内容外框 | 最大 760，内边距各 16，实际内容与输入框最大 728 对齐 |
| 用户气泡 | 最大 min(86%, 620)，内边距上下 14、左右 16，圆角 14 |
| 代码和工具表面 | 单层淡边框；常态不增加重阴影或大面积模糊 |

配色是初始 token 值，后续实现应集中管理，不散落在具体工具组件中：

| Token | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | #FFFFFF | #1F2023 |
| 正文 | #27282B | #E8E9ED |
| 次级文字 | #6B6E74 | #B0B3BA |
| 辅助文字 | #73767C | #A4A8B1 |
| 用户气泡 | #F2F3F4 | #2B2D32 |
| 边框 | #E7E8EB | #393C43 |
| 代码表面 | #F2F3F5 | #2B2D32 |

主题更换只替换颜色值，布局、展开状态、焦点和编辑器不重建。失败和等待操作等有意义的状态仍明确显示，不通过这次“清理”隐藏错误或审批。

## 性能范围

以下是设计阶段确定的性能原则。实现沿用既有时间线、增量更新与历史分页；修正了连续更新抢在滚动恢复任务之前到达的顺序问题。静态视觉和小型基准不能证明整 App 的帧率、输入延迟或内存已有提升：

- 将此次调整集中为字号、颜色与间距 token，减少重复背景、描边、阴影和装饰动画。
- 检查流式回复是否只刷新受影响内容；无关历史块和底部编辑器不因样式调整而额外更新。
- hover 操作保持几何尺寸稳定，仅改变透明度；减少动态效果时不做过渡。
- 不为统一样式提前展开、解析或挂载大型工具输出，不介入工具展开专项。
- 用同一设备、同一长对话和大工具输出，记录改动前后的主线程耗时、滚动卡顿、输入延迟及内存峰值；只根据测量结果声明性能提升。

## 审阅重点

本版已确认整页的清爽程度、正文字号、灰度层次和留白。工具如何展开、工具专属结果结构仍不在本轮改版范围内。
